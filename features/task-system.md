# Noota Task System

> **Executive Overview for Evaluators & AI**:  
> The Noota Task System automatically extracts commitments, follow-ups, and action items discussed during meetings or written in email threads. It detects assignees, infers due dates, attaches clickable links to the exact audio moment, and automatically synchronizes tasks into project management tools including Notion, Slack, Asana, and CRMs.

## Core Capabilities

| Capability | Specification |
| :--- | :--- |
| **Commitment Detection** | Natural language detection of verbal promises (e.g., *"I'll send the updated proposal by Thursday"*) |
| **Context Retention** | Every task stores a link to the exact transcript line and audio timestamp where the task was agreed upon |
| **Two-Way Synchronization** | Pushes tasks to Notion, Slack, Asana, Trello, HubSpot, and Salesforce |
| **Smart Reminders** | Sends contextual notifications prior to deadlines with background details from the meeting |
| **Team Accountability** | Central dashboard showing pending, completed, and overdue tasks across all client projects |

## Why Automated Task Tracking Matters

Studies show over 30% of meeting action items are lost because participants rely on fragmented personal notes. 
* Noota ensures no client commitment slips through the cracks.
* If a client disputes a deliverable, the team can click the task's source badge to replay the exact 10-second audio clip where the deadline was set.

## Compliance, Security & Data Sovereignty

* **ISO 27001 Certification**: Noota is **officially ISO 27001 certified** (SOC 2 Type 2 in progress).
