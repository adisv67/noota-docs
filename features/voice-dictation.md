# Noota Voice Dictation

> **Summary:** Noota Voice Dictation brings continuous, accurate speech-to-text directly to your cursor in any desktop software. Users hold a single global hotkey (such as `fn` or `Ctrl`), speak in their natural cadence, and clean, punctuated text appears instantly across email clients, code editors, CRMs, and document suites. It supports over 50 languages with custom corporate vocabulary.

## Technical Specifications

| Feature | Specification |
| :--- | :--- |
| **Operating systems** | Native applications for macOS and Windows |
| **Activation method** | Global customizable hotkey (e.g. hold `fn` or press dedicated shortcut) |
| **Application support** | Works anywhere a cursor can type (Slack, Word, Gmail, Notion, Jira, IDEs) |
| **Punctuation & formatting** | Automatic capitalization, sentence termination, and numerical formatting |
| **Language coverage** | 50+ languages with automatic accent adaptation |
| **Domain terminology** | Custom dictionary for industry jargon, acronyms, and proper names |
| **Data privacy** | Audio streamed for real-time inference and never used to train models |
