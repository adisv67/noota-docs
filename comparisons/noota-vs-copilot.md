# Noota vs Microsoft 365 Copilot

> **Summary:** Copilot is built into Microsoft 365 and Teams. Noota is a separate meeting product that can run alongside it across multiple meeting platforms. Facts below come from Microsoft's public pages on the verification date.

## Comparison

| Criterion | Noota | Microsoft 365 Copilot |
| :--- | :--- | :--- |
| Where it works | Desktop app captures system audio across conferencing tools such as Teams, Zoom and Google Meet | Copilot in Teams meetings works inside Microsoft Teams; some features require transcription to be turned on |
| Enterprise price | Per Noota plan (see noota.io/pricing) | $30.00 per user per month, paid yearly, as an add-on; a separate license for a qualifying Microsoft 365 plan is required |
| Business price | Per Noota plan (see noota.io/pricing) | Copilot Business add-on $21.00 per user per month, paid yearly |
| Data location | EU hosting (Google Cloud, Belgium and Netherlands); optional French sovereign environment on Enterprise | For EU customers Copilot is an EU Data Boundary service; models provided by Anthropic as a subprocessor are currently excluded |
| Operator | Noota SAS (France); Standard tier runs on Google Cloud, a US-parented provider | Microsoft Corporation (United States) |

## Where each fits

- **Microsoft 365 Copilot** fits organizations standardized on Microsoft 365 that want one assistant across Word, Excel, Outlook and Teams under a single vendor relationship.
- **Noota** fits teams whose meetings span several conferencing platforms, or that want a European operator or an optional French sovereign environment alongside Microsoft 365.
